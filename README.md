## 📌 О проекте

В 2023–2026 годах мировой и российский рынки полупроводниковой памяти столкнулись с беспрецедентным кризисом:
* Твердотельные накопители (SSD) подорожали в **2–2.5 раза** по сравнению с минимумами лета 2023 года.
* Оперативная память стандарта DDR4 (ставшая уходящим стандартом) подорожала в **3.5–4.5 раза** из-за закрытия производственных линий и дефицита складских остатков.
* Модули DDR5 подорожали в **2–2.5 раза** из-за переориентации производственных линий ведущих вендоров (Samsung, SK Hynix, Micron) на выпуск сверхдорогой памяти HBM3e/HBM4 для серверов искусственного интеллекта.

Апгрейд пользовательского ПК для школьников, студентов и учебных заведений стал финансово обременительным.

**Цель проекта:** Исследовать экономические и технологические корни кризиса памяти и создать бесплатный прикладной программный комплекс **«MemOptima»**, который программными методами возвращает до **40–50% оперативной памяти** и высвобождает **десятки гигабайт на SSD** без покупки нового оборудования.

## 💡 Программное решение: «MemOptima»

Программа решает проблему нехватки аппаратных ресурсов двумя путями:
1. **Регенерация RAM (EmptyWorkingSet + Win32 API):** сброс раздутых рабочих наборов фоновых процессов в резервный пул ОС.
2. **Прозрачное сжатие SSD (NTFS CompactOS XPRESS8K):** сжатие игровых и прикладных папок без снижения скорости работы (распаковка до 2–3 ГБ/с силами многоядерного процессора).
3. **Глубокая санация кэша:** удаление скрытых временных файлов Discord, Telegram, Chromium Shader Cache.

### Результаты испытаний (тестовый стенд 8 ГБ RAM + 256 ГБ SSD):
* Занятость RAM: снижена с **86% (6.8 ГБ)** до **41% (3.2 ГБ)**.
* Освобождено на SSD: **17.8 ГБ** (за счет сжатия программ и чистки мусора).
* **Экономический эффект:** отсрочка покупки 16 ГБ RAM и 1 ТБ SSD сэкономила пользователю **свыше 22 000 рублей** по ценам ноября 2026 года.

## 🚀 Быстрый запуск

### Вариант 1: Запуск Python GUI версии (без установки SDK)
```bash
python src/memoptima_gui.py
```

### Вариант 2: Сборка и запуск C# (.NET) версии
```bash
cd src
dotnet build
dotnet run
```
*(Для корректной очистки памяти всех системных процессов рекомендуется запуск от имени Администратора)*.
